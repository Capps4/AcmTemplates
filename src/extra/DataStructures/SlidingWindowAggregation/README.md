# SlidingWindowAggregation

`SWAG<T,F>(f)` 维护 FIFO 队列，默认 `F=std::plus<T>`。`push(v)` 在队尾插入，`pop()` 删除队首；`query()` 按入队顺序返回全部元素的聚合值，`size()`、`empty()` 查询队列状态。删除和聚合要求队列非空；重建对象清空。

`f(const T&,const T&)` 必须可 const 调用、结合且对 T 封闭，不要求交换、幂等或逆元。T 支持复制和移动，不要求默认构造或单位元；运算和值的复制成本由使用者保证。内部保存值和左右两个方向的栈聚合，不借用入队参数，返回聚合值的副本。若 T 自身是视图，底层生命周期仍由调用者维护。

按常数成本的 T 和 f 计，push、pop 均摊 `O(1)`，单次搬栈最坏 `O(n)`；query 为 `O(1)`。空间为队列峰值大小 `O(n)`，vector 容量会保留。测试采用字符串连接、模仿射复合和朴素 FIFO oracle，覆盖非交换运算、两栈交替和非默认构造类型。现版结果见测试报告；OJ 性能目标尚未验证。
