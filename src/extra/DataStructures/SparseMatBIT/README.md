# SparseMatBIT

`SparseMatBIT<T,Key=int>(pts)` 接收所有允许更新的 `(x,y)` 坐标，构造时复制并压缩；重复坐标只登记一次，初值全为 `T{}`。`modify(x,y,v)` 给点加 v，调用点必须在原始 pts 中，不能只分别登记 x 和 y。构造后不能新增更新坐标；重建对象清空。

`prefixQuery(x,y)` 返回满足 `px < x` 且 `py < y` 的点值之和；`rangeQuery(xl,yl,xr,yr)` 返回半开矩形 `[xl,xr) × [yl,yr)` 的点值之和。端点是实际坐标，不是压缩下标，可任意选取，不需登记；空矩形返回零。空点集可以查询，不能更新。坐标只比较，不进行加减；Key 支持 `<`、`==`，避免整型极值边界的减一溢出。

T 为交换加法群，默认构造得到零，支持 `+` 和 `-`，运算不得溢出。设输入登记数为 k，构造 `O(k log² k)`，修改/查询 `O(log² k)`，空间 `O(k log k)`；每个外层 Fenwick 节点仅保存覆盖点的 y 坐标。它适合预知更新点、在线修改查询的场景。

测试使用原始坐标字典逐点求和 oracle，覆盖重复点、空集、边界坐标和稀疏大范围数据。基准包含稀疏对角线和交叉坐标，checksum 使用独立求和公式；现版结果见测试报告；OJ 性能目标尚未验证。
