# RollbackDSU

`RollbackDSU(n)`，顶点 `[0,n)`。`Union(x,y)` 按大小合并，返回是否连接了两个分量；自环和已有连通关系返回 false，不记录历史。`find`、`same`、`size(x)` 分别查询代表元、连通性和分量大小。采用负根大小，无路径压缩，查询与合并最坏 `O(log n)`。

`snapshot()` 返回成功合并的历史长度，`rollback(s)` 撤销到该长度，耗时与撤销的成功合并数成正比。快照只对同一对象当前历史分支有效；撤销后被丢弃的未来快照不可复用，即使长度再次相同。重复回滚当前快照无操作；可回滚到 0，恢复独立顶点。`n` 为非负 int，空间 `O(n)`，有效历史最多 `n-1` 条；重建对象重置。

正确性用例覆盖重复合并、分支回滚、图遍历 oracle 和大规模平衡合并。性能场景区分平衡合并与反复撤销，保留 checksum；现版结果见测试报告；OJ 性能目标尚未验证。
