# Rerooting

[code.hpp](code.hpp)

`Rerooting(adj, e, merge, lift, finish)` 在无向森林上计算每个点作为根时的结果，输出 `ans[x]`。顶点从 0 开始，邻接表须双向、无自环或重边、无环；支持空森林和孤立点。n、邻接表长度须用 int 表示。

T 支持复制与赋值，不要求默认构造。e 是 merge 的左右单位元；merge 满足结合律，无需交换律。三个回调纯粹地返回 T：

- `merge(a,b)` 按顺序合并两个邻居贡献。
- `finish(a,x)` 在已合并的邻居贡献上加入点 x。
- `lift(a,x,y)` 将包含 x 的结果沿边 x→y 变成对 y 的贡献；边权可由回调闭包读取。

对任一根，点 x 严格按 `adj[x]` 的原顺序合并其子节点贡献；向某个邻居传递消息时只跳过该邻居，不把父边移到首位。先 finish，再 lift；最终 `ans[x]` 已包含 finish。

例如 T 为 `{点数, 距离和}`：merge 分别相加，finish 将点数加一，lift 将距离和加上点数，即得到每个点到同一连通分量各点的距离总和。

两轮显式遍历和前后缀合并，避免深链递归。回调及 T 操作 O(1) 时，总时间和空间均为 O(n)；若 T 为字符串等变长结构，还须计入复制及回调实际成本。对象只保存结果，不借用图或回调，无 reset；重建即可重新计算。

参考 [Nyaan Rerooting](https://nyaannyaan.github.io/library/tree/rerooting.hpp.html) 的前后缀排除思路，本实现保留原邻接顺序并使用显式遍历。

正确性以逐根 BFS 距离和、逐根递归字符串表示作独立 oracle，覆盖森林、非交换运算、邻接乱序及长链/星形。性能与专用的距离和两遍 DP 对照；本机计时见测试报告，尚无 OJ 排名证据。
