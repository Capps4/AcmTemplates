# TreeHash

提供带种子的 64 位混合函数，未封装整棵树的同构算法。`TreeHash(seed)` 可固定种子，`operator()(uint64_t)` 使用 SplitMix64 的混合步骤和模 2^64 的无符号运算；全局 `f(x)` 使用共享 `treeHash`，跨翻译单元为同一实例。同一种子下，单次混合是 64 位整数的置换；用于 `1 + sum(f(childHash))` 等无序聚合时仍可能碰撞，不能作确定性同构证明。单次 O(1)、空间 O(1)，无缓存。

原公式把低 31 位与高位经过同一函数后相加，会导致 `f(1) == f(1ULL << 31)` 对所有种子成立。现已替换该公式，保持接口；相同种子生成的数值与旧版不同。测试使用固定碰撞回归、全部位位置、小规模有根树的精确括号编码与重编号对照，有限测试不构成聚合无碰撞的证明。
