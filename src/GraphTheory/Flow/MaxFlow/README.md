# MaxFlow

[code.hpp](code.hpp)

`Flow<T>` 使用 Dinic：bfs 建层图，递归 dfs 按当前弧增广。顶点从 0 开始，`add` 返回正向偶数边 ID，反向为 id^1；支持平行边、自环、初始反向容量和 `newNode`。

`work(s,t,lim)` 返回本次新增流量，可重复调用继续增广；s=t 或 lim=0 返回 0。T 为非 bool 算术类型，容量非负，浮点容量有限；每对边初始容量之和须可表示。

`getReach` 返回残余可达集合，`getCuts` 返回分界端点对。汇点不再可达时才是最小割；原图割容量须用调用方保存的原始容量计算。

标准最坏时间 O(n²m)、存储 O(n+m)，递归栈深度随增广路径长度增长。
