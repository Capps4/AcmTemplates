# StringHash

[code.hpp](code.hpp)

`StringHash` 为多维前缀哈希；实现为 `_strhash::Impl<D,B,P>`。`getArray(l,r)` 返回各维结果，`getU64(l,r=-1)` 无损打包 1/2 维，-1 表示到结尾。下标从 0 开始，区间 `[l,r)`，空区间为零。

支持字节、NUL 视图及整数序列，C 字符串须 NUL 终止。构造后不借用输入。比较哈希须同时比较长度，仍可能碰撞。

默认底数每进程随机且跨翻译单元共享；复现时使用具有静态存储期的固定 B/P 数组，要求 P>1、0<B<P 且之后不修改。共享幂表扩容需外部同步。

构建 O(Dn)、查询 O(D)、存储 O(Dn+共享幂表)，序列长度须小于 INT_MAX。
