# 本轮简化前后对照

这是 Original 风格重塑阶段的历史对照；其后严格警告检查又做了小幅修改，当前版本性能以各模块 Performance.md 为准。基线为 BeforeContestReshape.tar.gz 内的 Final，不是 Original。GNU++17 GCC 15.2、-O2，同一进程内执行相同数据和操作，校验值一致；预热后各测七轮，取中位数。最终计时串行执行，没有同时运行编译或其他评测。原始样本、源码校验值及机器信息见 Results.json。

单位为毫秒。结果仅代表本机、本次场景。

| 模块 / 场景 | 简化前 | 简化后 | 变化 |
| --- | ---: | ---: | ---: |
| 最小轮转 / alphabet-1 | 0.495 | 0.442 | 时间减少 10.7% |
| 最小轮转 / alphabet-2 | 3.426 | 2.920 | 时间减少 14.8% |
| 最小轮转 / alphabet-26 | 1.052 | 0.980 | 时间减少 6.8% |
| 主席树 / 构建 | 15.469 | 12.849 | 时间减少 16.9% |
| 主席树 / 区间计数 | 29.992 | 30.002 | 基本持平 |
| 主席树 / kth | 23.207 | 24.409 | 时间增加 5.2% |

| RMQ / 有状态比较器构建 30K | 0.152 | 0.154 | 基本持平 |
| Fenwick / 线性构建 200K × 20 | 7.862 | 7.611 | 时间减少 3.2% |

这些数据支持减少包装和重复分支没有普遍破坏热路径；其中最小轮转和主席树构建有较明显收益。几百分点的差异可能随机器负载、缓存及编译器变化，不能作为跨机器保证。其余模块与 Original 的对照见各模块 Performance.md。
