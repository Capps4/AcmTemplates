# 本机性能对照

相同输入及校验和；各预热一次、计时七轮取中位数，场景间交替先测旧版/新版。GCC/Clang 编译器屏障保护计时边界。七轮原始数据和编译命令保存在 Results.json。

倍率为旧版耗时 / 新版耗时，大于 1 表示本场景新版较快；不代表其他输入或机器。

| 场景 | 旧版 ms | 新版 ms | 倍率 |
| --- | ---: | ---: | ---: |
| read-small-1M | 6.142 | 5.908 | 1.03961 |
| write-small-1M | 8.341 | 8.316 | 1.00301 |
| read-i64-1M | 11.089 | 11.043 | 1.00417 |
| write-i64-1M | 12.465 | 12.534 | 0.994495 |

编译器：g++-15 (Homebrew GCC 15.2.0_1) 15.2.0。
平台：macOS-15.7.4-arm64-arm-64bit。
